### 一、AI编程开发流程演示

#### 1. 需求分析与MVP设计

- MVP核心功能：与AI沟通确定最小可行性产品，初版仅保留导入和阅读TXT文本的核心功能，暂不实现目录解析与多背景色设置。
- 明确应用定位：在需求沟通阶段需明确告知AI目标为原生桌面应用，避免AI默认生成网页端方案导致后续文档大幅修改。

#### 2. 技术选型与文档编写

- 技术栈选择：基于当前电脑部署环境，推荐使用Electron框架开发桌面端应用，其生态更成熟且契合外部技术。
- 文档生成与校验：利用AI生成PRD产品文档和技术文档，需人工仔细通读校验，确保无遗漏或错误（如纯前端字样）。
- 规范Agent行为：编写Agent配置文件，强制要求AI在每次改动后执行Git保存版本，并编写或更新相关测试，确保交付前测试通过。

#### 3. 代码生成与界面优化

- 初始版本生成：AI根据PRD和技术文档生成初版代码，样式相对简陋。
- 界面UI优化：要求AI优化页面，使其简洁大方并适当添加图标，最终达到满意的视觉呈现效果。

#### 4. 测试与Bug修复

- 人工验证进度保存：人工测试发现阅读完成后返回首页，阅读进度未能正确更新。
- 修复记忆阅读位置：进一步测试发现应用未能记住上次退出的具体页面，需继续要求AI修复该Bug。

### 二、应用打包与部署

#### 1. 打包生成与图标设置

- 生成EXE文件：完成开发后，通过打包命令在dist文件夹中生成EXE文件，可直接分享给他人使用。
- 自定义应用图标：建议在打包前设置符合应用内容形象的自定义图标，替换默认图标。

#### 2. 打包故障排查

- 网络镜像源配置：终端直接打包失败，AI排查发现是因未设置网络镜像源导致国外下载链接过慢，AI自动解决该问题并打包成功。
